# 과제
- sqlite db 안에서 위/경도를 읽어와서, shp 공간정보에서 어느 폴리곤(행정구역)에 포함되는지를 판단하여 매칭한 뒤, 다시 sqlite db 에 기록

# 기술스택
- 윈11, python, uv 사용중, 라이브러리는 알아서 제안
- `emd.zip` 파일 안에 shp 공간정보 있음, 폴리곤 약 5천개로 각각 법정동 기준 읍면동을 나타냄, crs 는 `+proj=tmerc +x_0=1000000 +y_0=2000000 +lon_0=127.5 +k_0=0.9996 +lat_0=38 +ellps=GRS80`
- `01_shp_matching.py` 라는 한개의 스크립트 파일로 코드 작성

# 코드
- `emd.zip` 파일을 미리 로드

- `raw.sqlite` db 안 `marketmap` 테이블 에서 `emd_cd` 가 NULL 인 row 를 읽어옴, row 를 몇개씩 읽어야 효율적일지는 알아서 판단
- row 의 칼럼이 `lon`, `lat` 은 각각 경도, 위도를 나타냄, 이 좌표가 `emd.zip` 안에서 어느 폴리곤에 포함되는지를 판단
- 특정 폴리곤에 포함될 경우, 그 폴리곤의 `EMD_CD` 속성을 읽어옴, 숫자지만 text 형식으로 db 의 동일한 `emd_cd` 칼럼에 삽입
- 만일 경도, 위도 정보가 잘못되었거나, 어느곳도 포함되지 않는다면 "-1" 을 `emd_cd` 칼럼에 삽입

- 청크 한단위가 완료되면, 콜솔과 `01_shp_matching.log` 파일에 로그 출력
- 로그 출력할 땐 스크립트 시작부터 로그 출력시점까지 얼마나 시간이 경과했는지 추가
